NexisPhos Research Lab — Official Website

The official multi-page website for NexisPhos Research Lab (NPRL), an applied software studio based in Indore, India. NPRL builds websites, web applications, and AI-driven systems for ambitious businesses while training the next generation of engineers through its cohort-based Fellowship Program.

This repository contains the complete production-ready static website — 13 hand-crafted HTML pages including a homepage, services index, six service detail pages, portfolio grid, case study, dedicated fellowship landing page, about page, and a multi-channel contact page with a WhatsApp-integrated intake form.

Built with vanilla HTML, CSS, and JavaScript — no frameworks, no build step, no dependencies. Designed for fast deployment to Vercel, Netlify, Firebase Hosting, or GitHub Pages. The shared design system uses Instrument Serif and IBM Plex (Mono + Sans) on a dark editorial palette with a lime accent, prioritizing typography, performance, and SEO over visual gimmicks.

Key features include a mobile-first responsive layout, full-screen mobile drawer navigation, scroll-reveal animations, accordion FAQ sections, transparent pricing tiers, a fellowship comparison table, and a working WhatsApp-routing contact form. All contact details are pre-configured.

Headquartered in Indore, MP. Engineering the digital future, one experiment at a time.
